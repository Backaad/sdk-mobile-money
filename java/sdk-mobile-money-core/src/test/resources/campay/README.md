# Campay fixtures

Responses used by the WireMock tests. Their shape comes from the examples published by Campay
(official Python SDK README, `campay` 1.1.0 on PyPI) and, where marked, from third-party client
libraries. See `docs/providers/campay.md` for what is confirmed and what is still to be confirmed.

Token values are fake test values, never real keys.
